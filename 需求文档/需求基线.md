## 1. 项目概述

### 1.1 目标
对水弹玩具发射器波箱内部运作进行**纯数据模拟**（无图形动画）：
在给定配置参数下，输出单射击循环内各部件的运作时序，判定是否存在
打齿、推嘴归位不及时、供蛋窗口不足、气密不严、初速超标等问题，
并给出切齿方案建议、是否需要延时器、是否需要切拉桥旗等结论。

### 1.2 用户与使用场景
水弹玩家/改装者在改切齿、换气缸、换弹簧、改供蛋方式前，用数据模拟
预判风险，降低实弹试错成本。

## 2. 术语定义（已与用户确认）

| 术语 | 定义 |
|---|---|
| 二号波 | 通用二号波箱规格 |
| 蛋糕齿 / 切齿 | 扇齿上与活塞啮合的齿；去除部分齿称"切蛋糕齿" |
| 前切 | 切掉先啮合侧的齿 → 活塞拾取时刻**推迟** |
| 后切 | 切掉释放侧的齿 → 活塞释放时刻**提前** |
| 前后同切 | 行程缩短更多 |
| 天梯 / 拉桥 | 由扇齿凸轮槽驱动推嘴往复的零件；"拉桥旗"为插槽凸起 |
| 推嘴 | 供弹嘴；缩回=供蛋，回位到位=气密就位 |
| 打齿 | 活塞未归位时扇齿再次啮合齿条，半齿撞击崩齿 |
| 气密不严 | 活塞释放（压气）时推嘴未回位到位，漏气 |
| 供蛋窗口 | 推嘴完全缩回 → 开始回位之间的时间（最大开度停留期；✅v4.5/v4.6 实测澄清：完全缩回 = 开始达到最大幅度、开始回位 = 最大幅度结束，常规拉桥实测停留 20°（柱位角 +40°→+60°，✅v4.6 类推为通用默认基准）；无停留齿轮箱下为 0 属实；✅v4.5 切旗保留停留期——脱离于最大幅度结束）；另有指标「喷嘴未密闭时段」= 推嘴开始缩回 → 气密就位（✅v4.4 用户确认双指标显示） |
| 延时器 | 推迟推嘴回位、加宽供蛋窗口的配件（✅v4.7 参数直接生效：提前/延时度数非零即视为已安装并直接影响供弹窗口；旧「安装延时器」开关废弃，接受但忽略） |
| 切拉桥旗 | 使推嘴提前回位的改装手段 |
| 曲线模式 / 固定转速模式 | 选取 电机.型号 = 曲线模式（按 CHAOLI 性能曲线计算负载转速，负载系数固定 1、标称转速锁定为曲线空载值，均不可修改）；未选型号 = 固定转速模式（按标称 RPM × 负载系数计算） |
| 供蛋方式上限 | 供蛋机构最高供弹速率：普通波轮 30 / 高级波轮 60 / 压力弹匣 80 发/秒（✅v3.4 澄清：= 实际支持发射的能力，直接与射速比较；不换算「每发平均供蛋时间」，无「最小供蛋间隔」派生） |

## 4. 功能需求

### FR-01 时序模拟引擎
- FR-01.1 扇齿周期 = **拉动弧段 + 空转弧段**（变转速）：拾取角→释放角按电机
  负载转速（弹簧负载）、其余弧段按近空载转速（曲线模式负载系数固定 1，
  即按曲线空载转速）分段换算；
  固定转速模式按匀速（标称 × 负载系数）。齿比支持 13:1 / 16:1 / 18:1。
- FR-01.2 角度基准：齿轮角 0° = 无切时活塞拾取角；凸轮槽事件固定于扇齿；
  前切 n 齿 → 拾取角 = n × 12°；后切 m 齿 → 释放角 = 192° − m × 12°
  （满拉弧 192°，✅v3.9 实测更正：每齿 12°、15 齿距占 180°）。
- FR-01.3 活塞行程 = 满行程（60.5 mm） × min(剩余咬合齿数, 14) / 14；
  剩余咬合齿数 = **min(现存蛋糕齿 = 扇齿满啮合齿数 − 前切 − 后切, 计整齿数)**
  （✅v4.10 用户口径更正：切齿切的是蛋糕齿、天梯齿不减少——取代旧
  「min(扇齿满啮合, 计整齿数) − 前切 − 后切」错误口径），其中
  **天梯齿数**（✅v3.1 新增 / ✅v3.2 更正：默认=原装 13.5，半齿=第二齿磨低
  防咬合但仍整齿咬合 → 计整齿 13.5→14、11.5→12，可覆盖，校验范围 4~24）。
  原装咬合 14 齿对应满行程实测 60.5mm（默认行为/校准锚点不变）；
  **切齿合计 ≤2 齿（现存蛋糕齿 ≥14）时行程不减、仅移动拾取/释放时序**；
  合计 >2 齿后拉程随现存蛋糕齿缩短 → 储能/初速下降、电机负载减轻（曲线
  模式负载转速升高）；撞击剩余速度与回位稳定时间由联动积分决定。
- FR-01.4 弹道采用**气垫-弹丸联动数值积分**（步长 2μs）：
  开孔段部分漏气自由加速（✅v3.3：4 横槽有漏但非全漏，等效多变
  γ×开孔段保留系数，默认 0.6 估算）→ 密封后绝热压缩 + 气垫减速活塞 →
  弹丸同步加速 → 撞击缸头后弹丸继续膨胀加速；须满足能量守恒（弹丸+活塞
  残余 ≤ 弹簧输入功）。
  密封段按**水桶效应** = min(气缸系数×满行程, 实际行程)——孔位固定于缸体，
  切齿行程仍覆盖开孔段时密封容积不变，短于开孔段时全程密封。
- FR-01.5 管径-弹径间隙泄气损失与气动效率折减末动能。
- FR-01.6 电机负载模型（准静态法）：电机转速-扭矩特性近似线性
  `N(T) = N0 × (1 − T/T堵转)`；弹簧负载经扇齿分度圆半径（= 满行程弧长 ÷
  满拉弧角（弧度），✅v3.9 满拉弧 192°，原「÷ π」为 180° 旧口径）
  与齿轮比反射到电机轴；以**平均弹簧扭矩**求负载转速，以**峰值扭矩（拾取瞬间）**
  判堵转（≥ 堵转扭矩 = 电机堵转，无法完成循环）。曲线数据（11.1V =
  3.7V×3S 标称，实际满电 4.2V/芯）：超力无刷 4W8（空载 48000 RPM /
  堵转 473.7 mN·m）、超力无刷 3W9（39000 / 401.8）、超力有刷 3W5
  （35500 / 414.9）、超力有刷 3W3（32800 / 450.2）。未选电机型号时按
  标称转速 × 负载系数（默认 0.8，可覆盖）固定计算；曲线模式（选型号）下
  负载系数固定为 1、标称转速锁定为该电机曲线空载转速（✅用户确认 v2.7：
  两项均不可修改）。

- FR-01.7 电池模型（选配，须配合电机.型号）：实际工况按满电电压
  4.2V × 电芯数（✅用户更正：电机曲线基于标称 3.7V/芯，实际均充满至
  4.2V/芯，如 3S 满电 12.6V）；最大持续电流 = 容量(Ah) × 放电倍率C；
  电机峰值电流需求（拾取瞬间，扭矩-电流线性、与电压无关）超过电池能力时
  电压按 `保持率 = 限流 ÷ 峰值需求` 自满电起算跌落，转速与堵转扭矩同比例
  缩放；输出理论续航（容量 ÷ 拉拔期平均电流 × 周期）。
  缺省参数：3S / 1400mAh / 30C；未配置电池按曲线测试电压 11.1V
  （3.7V×3S 标称）理想电源计算。

- FR-01.8 改装件时序（二者可组合）：
  延时器 → **角度参数模型（✅v4.0 用户需求）+ 参数直接生效（✅v4.7）**：以两个
  直接角度参数描述——
  `延时器提前度数`（比原拉桥柱**更早接触**拉桥旗的转角，默认 0°）→ 推嘴开始
  缩回与完全缩回（供蛋窗口开始）提前该角度（✅v4.3 起不再钳制 0°：拉桥柱
  位置可负，缩回允许早于拾取；供蛋窗口开始仍钳制 ≥ 0°）；
  `延时器延时度数`（比原拉桥柱**更晚离开**拉桥旗的转角，默认 0°）→ 推嘴回位
  起始/完成推迟该角度 → 供蛋窗口加宽（提前 + 延时联合）、气密裕量同步减小。
  提前/推迟量按所在弧段转速换算 ms，随射速自动缩放。✅v4.7 参数直接生效：
  度数非零即视为已安装延时器并直接影响供弹窗口，无需安装开关（旧
  `改装.安装延时器` 开关废弃——接受但忽略；兼容：开关=true 且未显式配置
  延时度数 → 按旧默认 36° = 原「1 孔」口径处理，显式度数含 0 优先）。
   ✅v4.9 实测标定：**2号延时器 = 提前 0° / 延时 40°**（docs/齿轮测试-2.txt——
   超力18比直斜齿加装后接触 −30°/完全缩回 +40° 不变、最大幅度结束
   +60°→+100°、柱旗脱离 +160°→+200°，由延时度数参数直接复现）。
  旧几何模型「延时器占孔数」（占孔数 ÷ 拉桥柱孔数 × 周期）弃用——旧键被
  接受但忽略；
  切拉桥旗 → **✅v4.5 语义澄清：拉桥旗打开到最大幅度并维持到最大幅度结束后
  即与拉桥柱完全脱离**（停留段保留 → 供蛋窗口不收窄；S 形缓冲恢复段切除）
  → 推嘴随后不受拉桥柱缓冲、由强力拉桥簧快速归位、更早恢复闭合（水弹进膛
  后快速气密）：回位起始 = 最大幅度结束角（cam_return_start_deg）、回位完成
  提前 `切拉桥旗提前ms`（默认 3ms 估算）→ 气密裕量增大；需搭配更强拉桥簧，
  否则实际气密时刻会晚于估算（报告中已提示）；
  ✅v4.8 切旗后延时器延时度数**仍生效**（柱维持至最大幅度结束 + 延时度数才
  脱离——延时器延长最大开度停留期、供蛋窗口随延时加宽，切旗不再限制最大
  供弹窗口）、提前度数仍生效；
  带下限保护（回位完成不早于回位起始）。

- FR-01.9 天梯复位（回位稳定）模型：撞击后天梯以 `回弹系数 × 撞击速度`
  反弹，由主弹簧推动复位（单自由度简谐，`settle_time_ms`）：
  复位时间 = 2·atan(v_r/(ω·x0))/ω（ω=√(k/m)，x0=撞击时弹簧压缩量=预压）
  —— 弹簧刚度、压缩长度（预压）越大复位越快，撞击越重复位越久；
  下限 2 ms。主弹簧满压长度按「装配长 − 实际行程」派生（随切齿变化，
  不再使用独立实测值）。

- FR-01.10 拉桥柱位置（✅v4.3 用户新增，网页「齿轮」分区参数）：数值 =
  拉桥柱在哪一颗齿的下方，第 1 颗齿下方 = 0、+1 = 下一颗齿（每齿 12°），
  允许小数（0.5 = 两齿之间）与负数（−2 = 拾取前 2 齿距，缩回早于活塞拾取，
  校验范围 −16 ~ 30）；✅v4.6 凸轮槽全部事件角以柱位角 = 位置 × 每齿扇齿角
  为基准平移派生（解析层未显式覆盖对应角时派生，显式覆盖任一角该角优先）：
  缩回起点角 = 柱位角 − 拉桥旗接触提前角、完全缩回角 = 柱位角 + 40°、
  回位起始角 = 柱位角 + 60°、回位完成角 = 柱位角 + 160°。✅v4.6 实测基准
  （docs/齿轮测试-1.txt，常规拉桥，柱位0/拾取角0°）：接触 −30°（提前角 30°，
  拾取前缩回）、最大幅度开始 +40°（供蛋窗口开始）、最大幅度结束 +60°
  （供蛋窗口结束，停留 20°）、柱旗完全脱离 +160°（气密就位）——该时序
  **类推到所有同柱位齿轮**，柱位不同按柱位角平移推算（原估算默认
  0°/50°/144.4°/164.4° 由实测取代）。
  **柱位以未前切（前切=0）的原始齿序为基准、固定于扇齿**：前切 n 齿仅使
  拾取角后移至 n × 每齿角，柱位角不变——柱位角 < 拾取角时推嘴缩回早于
  活塞拾取，时序按扇齿实际转角与分段转速计算。延时器提前度数不钳制 0°
  （缩回可早于拾取）。齿轮预设「超力18比直斜齿」为该实测配置（柱位 0）。

### FR-03 判定规则（10 项，分级：通过 / 警告 / 危险）

## 6. 模型假设与已知简化
1. 活塞由静止被弹簧推动；开孔段泄压、密封段绝热压缩、气垫缓冲、
   弹丸联动加速均参与积分；
2. 水弹出有效推力行程后的背压减速忽略；弹丸管内摩擦并入气动效率；
3. 推嘴回位按凸轮角度硬性驱动（实际拉桥簧有柔性延迟，模型偏乐观）；
4. 供蛋窗口从推嘴完全缩回起算（实际蛋可提前进入）；窗口仅作时序信息、
   不参与判定（✅v3.4：供蛋能力上限=实际支持发射的能力）；
5. 弹簧刚度表、预压、活塞质量、余隙容积、凸轮槽角度为估算值；
6. 未选电机型号时按标称转速×负载系数（0.8）计算；选型后按电机曲线计算
   （负载系数固定 1、标称转速锁定曲线值，均不可修改，✅用户确认 v2.7）；
7. 天梯复位按主弹簧-活塞简谐模型（刚度/压缩长度影响复位速度；回弹系数
   0.5 为估算值）；满压长度按「装配长 − 行程」派生；
8. 气缸有效容积为水桶效应：min(气缸系数×满行程, 实际行程)——孔位固定于
   缸体，切齿行程仍覆盖开孔段时密封容积不变（推嘴时序判定随孔位提前/
   推后相应变化：高百分比缸+重后切时开孔缓冲显著减小）。
