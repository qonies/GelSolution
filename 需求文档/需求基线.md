## 1. 项目概述

### 1.1 目标
对水弹玩具发射器波箱内部运作进行**纯数据模拟**（无图形动画）：
在给定配置参数下，输出单射击循环内各部件的运作时序，判定是否存在
打齿、推嘴归位不及时、供蛋窗口不足、气密不严、初速超标等问题，
并给出切齿方案建议、是否需要延时器、是否需要切拉桥旗等结论。

### 1.2 用户与使用场景
水弹玩家/改装者在改切齿、换气缸、换弹簧、改供蛋方式前，用数据模拟
预判风险，降低实弹试错成本。

## 2. 术语定义（已与用户确认）

| 术语 | 定义 |
|---|---|
| 二号波 | 通用二号波箱规格 |
| 蛋糕齿 / 切齿 | 扇齿上与活塞啮合的齿；去除部分齿称"切蛋糕齿" |
| 前切 | 切掉先啮合侧的齿 → 活塞拾取时刻**推迟** |
| 后切 | 切掉释放侧的齿 → 活塞释放时刻**提前** |
| 前后同切 | 行程缩短更多 |
| 天梯 / 拉桥 | 由扇齿凸轮槽驱动推嘴往复的零件；"拉桥旗"为插槽凸起 |
| 推嘴 | 供弹嘴；缩回=供蛋，回位到位=气密就位 |
| 打齿 | 活塞未归位时扇齿再次啮合齿条，半齿撞击崩齿 |
| 气密不严 | 活塞释放（压气）时推嘴未回位到位，漏气 |
| 供蛋窗口 | 推嘴完全缩回 → 开始回位之间的时间 |
| 延时器 | 推迟推嘴回位、加宽供蛋窗口的配件 |
| 切拉桥旗 | 使推嘴提前回位的改装手段 |

## 4. 功能需求

### FR-01 时序模拟引擎
- FR-01.1 扇齿周期 = **拉动弧段 + 空转弧段**（变转速）：拾取角→释放角按电机
  负载转速（弹簧负载）、其余弧段按近空载转速（曲线空载 × 负载系数）分段换算；
  固定转速模式按匀速（标称 × 负载系数）。齿比支持 13:1 / 16:1 / 18:1。
- FR-01.2 角度基准：齿轮角 0° = 无切时活塞拾取角；凸轮槽事件固定于扇齿；
  前切 n 齿 → 拾取角 = n × 11.25°；后切 m 齿 → 释放角 = 180° − m × 11.25°。
- FR-01.3 活塞行程 = 剩余齿数 × 每齿角 ÷ 180° × 满行程（60.5 mm）。
- FR-01.4 弹道采用**气垫-弹丸联动数值积分**（步长 2μs）：
  开孔段泄压自由加速 → 密封后绝热压缩 + 气垫减速活塞 → 弹丸同步加速 →
  撞击缸头后弹丸继续膨胀加速；须满足能量守恒（弹丸+活塞残余 ≤ 弹簧输入功）。
- FR-01.5 管径-弹径间隙泄气损失与气动效率折减末动能。
- FR-01.6 电机负载模型（准静态法）：电机转速-扭矩特性近似线性
  `N(T) = N0 × (1 − T/T堵转)`；弹簧负载经扇齿分度圆半径（= 满行程弧长 ÷ π）
  与齿轮比反射到电机轴；以**平均弹簧扭矩**求负载转速，以**峰值扭矩（拾取瞬间）**
  判堵转（≥ 堵转扭矩 = 电机堵转，无法完成循环）。曲线数据（11.1V）：
  超力无刷 4W8（空载 48000 RPM / 堵转 473.7 mN·m）、超力有刷 3W5
  （空载 35500 RPM / 堵转 414.9 mN·m）。未选电机型号时按标称转速 × 负载系数
  （默认 0.8）固定计算；曲线模式下负载系数作为最终降额乘数（默认无刷 0.9 /
  有刷 0.8，只缩放负载转速，不影响扭矩/堵转/电流）。

- FR-01.7 电池模型（选配，须配合电机.型号）：标称电压 = 3.7V × 电芯数；
  最大持续电流 = 容量(Ah) × 放电倍率C；电机峰值电流需求（拾取瞬间，
  扭矩-电流线性）超过电池能力时电压按 `保持率 = 限流 ÷ 峰值需求` 跌落，
  转速与堵转扭矩同比例缩放；输出理论续航（容量 ÷ 拉拔期平均电流 × 周期）。
  缺省参数：3S / 1400mAh / 30C；未配置电池按曲线电压理想电源计算。

- FR-01.8 改装件时序（可选布尔开关，二者可组合）：
  安装延时器 → 几何模型：扇齿一圈 10 个拉桥柱安装孔（每孔 36°），延时器
  相当于拉桥柱加粗一倍、占用 2 孔 → 维持推嘴最大开度，推嘴回位起始/完成
  推迟 `延时器占孔数`（默认 1 孔 = 36°，推迟量 = 占孔数 ÷ 拉桥柱孔数 × 周期，
  随射速自动缩放）→ 供蛋窗口加宽、气密裕量同步减小；
  切拉桥旗 → 切掉拉桥旗槽 S 形曲线的缓冲尾（槽形：前段大幅拉开、后段缓冲
  恢复）→ 推嘴更早、更快恢复闭合（水弹进膛后快速气密）：回位完成提前
  `切拉桥旗提前ms`（默认 3ms）→ 气密裕量增大、供蛋窗口不变；需搭配更强
  拉桥簧，否则实际气密时刻会晚于几何提前量（报告中已提示）；
  带下限保护（回位完成不早于回位起始）。

### FR-03 判定规则（11 项，分级：通过 / 警告 / 危险）
| # | 判定 | 规则 | 默认阈值 |
|---|---|---|---|
| 1 | 打齿风险 | 回位裕量 = 下一循环拾取 −（撞击 + 回位稳定）；≤0 危险，< 阈值 警告 | 2.0 ms |
| 2 | 气密时序 | 气密裕量 = 弹后压力显著建立时刻（超大气压 10%）− 推嘴回位完成时刻；<0 危险（气密不严），< 阈值 警告 | 1.0 ms |
| 3 | 供蛋窗口 | 窗口 < 0.5×最小供蛋间隔 危险；< 最小供蛋间隔 警告 | 按方式 |
| 4 | 供蛋速率 | 射速 > 方式上限 危险；> 90% 上限 警告 | 30/50/60 发/秒 |
| 5 | 啮合齿数 | 切齿后剩余齿数 < 8 危险（半齿啮合/脱齿） | 8 |
| 6 | 压气匹配 | 压气指数（行程比 × 气缸系数）< 0.60 警告 | 0.60 |
| 7 | 初速 | 估算初速 > 80 m/s 警告 | 80 m/s |
| 8 | 气量管长匹配 | 有效推力行程 < 内管长度 × 0.5 警告（内管过长/气量不足） | 0.5 |
| 9 | 出膛时序 | 上一发出膛时刻 > 下一发拾取时刻 警告（滞留/双供风险） | — |
| 10 | 电机负载 | 峰值反射扭矩 ≥ 堵转扭矩 危险（电机堵转，无法完成循环）；> 80% 堵转 警告（固定转速模式不判定） | 堵转 80% |
| 11 | 电池放电 | 配置电池时：电压保持率 < 75% 危险、< 90% 警告（含理论续航）；未配置 = 通过 | 保持 90% |

供蛋方式上限（用户确认）：普通波轮 **30 发/秒**、高级波轮 **50 发/秒**、
压力弹匣 **60 发/秒**；最小供蛋间隔 = 1000 ÷ 上限速率。

### FR-04 结论建议
- 推荐切齿方案（枚举前切/后切 0~3 齿共 16 种，按最差裕量归一化得分排序）；
- 是否需要延时器（供蛋窗口不足时，附缺口毫秒数与气密复核提醒）；
- 是否需要切拉桥旗（气密裕量不足时）；
- 初速提示（是否超 80 m/s 阈值及回调方向）。

## 6. 模型假设与已知简化
1. 活塞由静止被弹簧推动；开孔段泄压、密封段绝热压缩、气垫缓冲、
   弹丸联动加速均参与积分；
2. 水弹出有效推力行程后的背压减速忽略；弹丸管内摩擦并入气动效率；
3. 推嘴回位按凸轮角度硬性驱动（实际拉桥簧有柔性延迟，模型偏乐观）；
4. 供蛋窗口从推嘴完全缩回起算（实际蛋可提前进入，判定偏保守）；
5. 弹簧刚度表、预压、活塞质量、余隙容积、凸轮槽角度为估算值；
6. 标称转速直接计算射速，判定偏严苛。
