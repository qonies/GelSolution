# GelSolution — 水弹波箱运作数据模拟

对水弹玩具发射器波箱（通用二号波规格）内部运作做**纯数据模拟**（无动画）：
给定电机、齿轮比、切齿方案、气缸、弹簧、内管/水弹、供蛋方式等参数，输出单循
环内各部件运作时序，并判定是否打齿、推嘴归位是否及时、供蛋时间窗口是否足够、
气密是否可靠、水弹初速是否超标，最后给出切齿方案建议、是否需要延时器、是否
需要切拉桥旗。

## 使用方法

### 方式一：本地网页界面（推荐，实时调参）

```bat
python webui.py                # 启动后自动打开浏览器 http://127.0.0.1:8765/
python webui.py --port 9000    # 指定端口
python webui.py --no-browser   # 不自动开浏览器
```

- 左侧参数分 6 个分区卡片：**电机 / 齿轮 / 电池 / 气缸 / 弹簧 / 其他**
  （分区头部可点击折叠/展开，状态自动记忆），改任意
  参数（滑块/下拉/数值）右侧 **150ms 内自动重算**实时结果；
- 电机/齿轮/电池/气缸/弹簧 五区头部带**预设下拉**（✅v0.8.0）：选项来自
  `configs/presets/<分区>/<名称>.json`（预设名称=文件名，内置 22 套，可自行
  添加 JSON 文件扩展），选择预设=整区载入（未列出的参数恢复系统默认），
  手动修改该区任意输入自动转「自定义」；其他分区不设预设；
- 指标卡片（初速超阈值自动变红）、10 项判定、结论建议、单循环时序轴+事件表、
  16 种切齿方案对比表（当前方案高亮）；
- 支持当前配置 **导出/导入 JSON**（与命令行配置文件格式完全一致）、一键复制
  完整文本报告。

## 模型说明与假设

1. **角度基准**：扇齿齿轮角 0° = 无切齿时的活塞拾取角。凸轮槽事件固定在扇齿上，
   切齿后活塞拾取/释放角相对凸轮事件移动——这是切齿影响气密与回位裕量的机理。
   推嘴开始缩回锚定在「第 2 颗齿接触天梯」= 拾取 + 1 齿距（✅ 拉桥柱在第 2 齿下方）。
2. **前切 n 齿** → 拾取角 +n×齿距（拾取推迟）；**后切 m 齿** → 释放角 −m×齿距（提前释放）。
   两者都缩短活塞行程 → 弹簧总功减少（初速下降）、前冲加快、回位裕量加大；
   实际咬合齿数 = min(扇齿满啮合齿数, **计整齿数**)（✅v3.2 用户更正：默认
   天梯 13.5 齿，半齿=第二齿磨低防咬合但仍整齿咬合 → 13.5 计 14、11.5 计 12）
   ——原装咬合 14 齿对应满行程实测 60.5mm，实际拉程 = 满行程 ×
   min(剩余咬合, 14) / 14（超过封顶）：齿数越少拉程越短，
   储能/初速下降、电机负载减轻（曲线模式负载转速升高）；撞击剩余速度与
   回位稳定时间由气垫-弹丸联动积分决定（默认参数下拉程短时撞击剩余速度
   与回位稳定略降）。
   有效密封容积按水桶效应 = min(气缸系数×满行程, 实际行程)（见 7），切齿不叠加缩减。
3. **打齿判定**：回位裕量 = 下一循环拾取时刻 −（活塞撞击 + 气垫回弹稳定）。
4. **气密判定**：推嘴回位完成必须早于活塞释放；后切越多释放越早，越容易气密不严。
5. **供蛋判定**（✅v3.4 澄清）：弹匣/波轮的供蛋能力上限（普通波轮 30 /
   高级波轮 60 / 压力弹匣 80 发/秒）指其**实际支持发射器发射水弹的能力**，
   直接与射速比较（> 上限 危险、> 90% 上限 警告）——不换算「每发平均供蛋
   时间」（1000÷上限）与供蛋窗口对比；供蛋窗口（推嘴完全缩回→开始回位）
   仅作时序信息展示，窗口是否足够以实测供蛋为准。旧参数「最小供蛋时间ms」
   已弃用（配置键被接受但忽略）。
6. **动力学**：活塞由静止被弹簧推动（弹簧推力含传动效率），气垫参与减速
   （联动积分）；撞击后回位稳定按主弹簧-活塞简谐回位模型（`settle_time_ms`）：
   回弹速度 = 回弹系数×撞击速度，复位时间 = 2·atan(v_r/(ω·x0))/ω——弹簧刚度
   与压缩长度（预压）越大复位越快，撞击越重复位越久（注意：整枪对比时刚度
   更大的弹簧撞得也更重，净效果可能抵消）；主弹簧满压长度按「装配长 −
   实际行程」派生（随切齿变化）；弹簧刚度已按用户提供的二号波实测区间标定。
7. **初速模型（ballistics.py，气垫-弹丸联动积分）**：模拟真实过程——
   活塞释放后先在开孔段自由加速（不压缩）；活塞头盖过气孔后气体密封，
   随活塞前进绝热压缩，气垫同时反向减速活塞；弹后气压一升高水弹即沿
   内管加速，弹后容积增大反过来限制压力上升；活塞撞击缸头后容积只随
   水弹前进增大，气压降到大气压后无净推力（"有效推力行程"）。
   数值积分步长 2μs，能量守恒已验证（弹丸+活塞残余 ≤ 弹簧输入功）。
   管径-弹径间隙泄气 + 气动效率折减末动能。气缸类型 50%~100% = 开孔位置
   （以满行程标定、固定于缸体）；有效密封段按水桶效应 = min(气缸系数×满行程,
   实际行程)——行程仍覆盖开孔段时密封容积不随切齿缩减，行程短于开孔段时
   全程密封（密封段越短压力建立越快）。**加速长度由气缸
   实际有效气体容积决定，不是内管长度**——压力降至大气压即停止加速，
   管长匹配判定据此提示过长内管。
   **缸型-管长匹配（✅v3.5 分析）**：同一内管下初速随缸型存在峰值——
   缸越大密封容积越大，压力建立越慢、峰值越低（p_max：50缸 327 / 70缸
   313 / 100缸 275 kPa）但持续时间越长；弹丸出膛早（短管）时大缸的多余
   气量来不及做功 → 初速反而低。扫描数据（M90，初速 m/s）：
   50缸 58.9(210管)→71.7(700管)；100缸 53.4(210管)→74.1(700管)；
   峰值缸型随管长右移：210管≈50%、350管≈60%、500~700管≈80%。
   即"短管配小缸、长管配大缸"——与现实改装规律一致，大缸并非越大越快。
   **开孔段漏气口径（✅v3.3 用户更正）**：50%~100% 缸 = 在气缸相应位置
   对称开 4 条横槽漏气，但活塞经过极快，横槽来不及漏掉全部已压缩气体
   （有漏但非全漏）——开孔段按等效多变压缩 γ×「开孔段保留系数」（默认
   0.6 估算，0=全漏旧模型、1=完全不漏）建模：活塞盖孔瞬间弹后压力已
   建立（>1.1 大气压），密封段自该压力起算绝热压缩；气动效率随此模型
   重校准 0.21→0.243（保持 M90/70缸 ≈71 m/s 实测锚点）。
8. **电机负载与电池（motor.py）**：选配 电机.型号 后按 CHAOLI 11.1V 性能
   曲线计算（型号：超力无刷4W8 / 超力无刷3W9 / 超力有刷3W5 / 超力有刷3W3，
   曲线图见「电机性能曲线/」）——电机扭矩-转速线性 `N(T)=N0×(1−T/T堵转)`；
   弹簧负载经扇齿分度圆半径与齿轮比反射到电机轴，平均扭矩定负载转速，
   峰值扭矩判堵转。
   未选型号时按标称转速 × 负载系数固定计算（默认系数 0.8）。
8b. **负载系数（✅用户确认 v0.6.4：选型后锁定）**：曲线模式（选 电机.型号）
    下负载系数固定为 1、标称转速锁定为该电机曲线空载转速，两项均不可修改
    （JSON 显式配置不一致会报中文错误；网页输入框自动禁用并同步显示曲线值）；
    固定转速模式（未选型号）负载系数默认 0.8，可显式覆盖。
8c. **变转速循环**：拉动天梯受力的弧段（拾取→释放）电机带弹簧负载转得慢，
    释放天梯后的空转弧段接近空载转速、转得快——事件时刻按分段角度-时间
    转换（曲线模式周期 = 拉动段 + 空转段；固定转速模式按匀速）。
9. **电池模型**：实际工况按满电电压 4.2V × 电芯数（✅用户更正；电机曲线为
   标称 3.7V/芯测试，3S 满电 12.6V 较曲线电压 11.1V 高 ~13.5%）；最大持续
   电流 = 容量(Ah) × 放电倍率C；电机峰值电流需求（与电压无关）超电池能力时
   电压跌落 `保持率 = 限流 ÷ 峰值需求`（自满电起算），按保持率缩放转速与
   堵转扭矩；并估算理论续航（发）。
10. **改装件**：延时器几何模型——扇齿一圈 10 个拉桥柱安装孔（每孔 36°），装
    延时器相当于拉桥柱加粗一倍、占用 2 孔 → 推嘴回位推迟 1 孔 = 周期×1/10
    （默认 32ms 周期下 ≈3.2ms，随射速自动缩放）——维持推嘴最大开度、供蛋
    窗口加宽、气密裕量同步减小。拉桥旗槽为 S 形曲线（前段大幅拉开、后段
    缓冲恢复）：切拉桥旗 = 切掉 S 形缓冲尾 → 推嘴更早、更快恢复闭合
    （`切拉桥旗提前ms` 默认 3ms，气密裕量增大、供蛋窗口不变），代价是需
    搭配更强拉桥簧。两项通过
    「改装」配置块或网页复选框启用，可组合（有下限保护：回位完成不早于
    回位起始）。
