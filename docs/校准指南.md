# 器件参数实测校准指南（GelSolution）

> 适用于工程版本 v0.7.2（需求基线 v3.5）。本文档说明如何用**实测数据**校准
> 模拟器中的估算参数，使初速估算与时序判定（打齿/气密/供蛋）对齐到你的
> 实物枪况。所有实测值通过配置「器件参数覆盖」（网页同名输入框）填入。

## 3. 测试方法

### 优先级 1：静态测量（一次测量，全局受益）

1. **活塞组件质量**：活塞 + 活塞头 + 垫圈整体称重 → `活塞质量g`
   （水弹尼龙活塞通常 15~20 g）。
2. **余隙容积（灌水法）**：拔掉内管、活塞推到缸底，用注射器向缸头 +
   弹后死腔灌水计量 → `气缸余隙容积cm3`（估算范围 0.8~1.5）。
3. **弹簧刚度（两点差分法）**：每根弹簧分别压缩 x1=10mm、x2=30mm 记力值
   F1、F2，k = (F2−F1)/(x2−x1)（差分消除端部非线性）→ 更新 `弹簧刚度表`
   对应 M 档；顺带量自由长/装配长（预压自动派生，无需手填）。
4. **水弹抽样**：同批泡发弹抽 10 颗称重 + 卡尺量直径 → `水弹质量g`
   （直径按体积缩放自动处理）。

### 优先级 2：初速模型反标（对结论精度影响最大）

5. **锚点配置**：建议先做 **100% 缸 + 350 管 + M90**（模型实测锚点
   ≈71 m/s；100% 缸无开孔段，保留系数不参与，可单独定效率）。
   同配置打 5~10 发取中位数，反标：

   ```
   新气动效率 = 旧气动效率 × (实测初速 ÷ 估算初速)²
   ```

6. **隔离开孔段保留系数**：效率定准后，保持弹簧/管长不变，换 **50% 缸**
   与 **70% 缸** 各测一组——缸型之间的初速差基本只由保留系数决定，
   反推 0~1 取值（0=全漏旧模型、1=完全不漏）。
7. **管长扫描（验证性）**：同配置换 210 / 350 / 500 / 700 mm 内管各测一组，
   对照模拟的「有效推力行程」与「短管配小缸、长管配大缸」匹配趋势
   （210管≈50% / 350管≈60% / 500~700管≈80%）。
8. **泄气损失（可选粗修）**：对比 7.5管/7.2弹 与 7.3管/7.2弹 初速差，
   微调 `泄气损失系数`（与气动效率耦合，只能近似分离）。

### 优先级 3：时序与判定类

9. **凸轮槽三角度（角度盘法）**：拆开波箱，打印角度盘贴在扇齿端面
   （每齿 11.25°），手动慢转扇齿，观察推嘴动作，标记并记录：
   - 完全缩回（供蛋窗口开始）→ `完全缩回角`（估 50°）
   - 开始回位（供蛋窗口结束）→ `推嘴回位起始角`（估 144.4°）
   - 回位完成（气密就位）→ `回位完成角`（估 164.4°）
   缩回起点 11.25° 已按拉桥柱几何锚定，无需测量。
10. **撞击回弹系数**：抽出弹簧或换弱簧，240fps 慢动作拍活塞撞击缸头后的
    回跳，回弹速度 ÷ 撞击速度 ≈ 系数；不便观察时用实弹「打齿/不打齿」
    表现对照模拟回位裕量反推（注意模拟撞击过程在 1ms 量级，240fps
    时间分辨率 ~4ms，精度有限，建议多组取均值）。
11. **射速验证**：慢录像数 10 发计时（或录音数响）→ 对照模拟周期/射速；
    偏差大优先查负载系数与电机曲线口径。
12. **电机负载转速**：反光贴 + 光学转速计实测负载转速，与模拟对比 →
    微调 `传动效率`（0.85 为校准旋钮）。

### 优先级 4：供蛋与电池

13. **供蛋上限**：慢录像数波轮空转拨蛋频率，核对普通 30 / 高级 60 /
    压力弹匣 80 发/s 是否符合实物。
14. **电池跌落**：电压表并联电池，连喷观察压降，对照模拟「保持率」
    （满电 4.2V/芯 起算）；顺便核对续航估算口径（偏保守）。

## 4. 推荐执行顺序

1. 静态测量（优先级 1，第 1~4 项）；
2. 100% 缸锚点反标气动效率（第 5 项）；
3. 多缸型扫描隔离开孔段保留系数（第 6 项）；
4. 慢录像完成凸轮角度 + 回弹系数（第 9~10 项）；
5. **回归抽查**：用一份**未参与校准**的配置实测（如 M110 + 70缸 +
   350管 + 7.3管7.3弹，模拟 88.3 m/s 应触发初速警告），初速与判定级别
   均吻合 → 模型整体可信。

## 5. 数据填写方式

实测值写入配置「器件参数覆盖」（网页「器件参数覆盖」折叠区同名输入框）：

```jsonc
{
  "器件参数覆盖": {
    "活塞质量g": 18.5,
    "气缸余隙容积cm3": 1.2,
    "气动效率": 0.26,
    "开孔段保留系数": 0.55,
    "弹簧刚度表": { "M90": 0.60 },
    "完全缩回角": 48.0
  }
}
```

- 弹簧刚度表只需覆盖实测过的 M 档，其余沿用默认；
- 网页中清空某输入框 = 恢复该系统默认；
- 每把枪/每套弹簧建议单独保存一份 JSON（网页可导出）。

## 6. 测试注意事项

- **单变量原则**：每次只改一个器件，其余配置冻结并记录；
- 水弹同批、同泡发时长（直径/质量是初速波动最大来源之一）；
- 电池每次从满电（4.2V/芯）同一起点测试；
- 每组 ≥5 发取**中位数**（首发常偏低）；
- 测速仪对正弹道、弹体擦干，避免贴管壁读数失真；
- 记录环境温度（模型基准大气压 101.3 kPa，极端海拔/温度有小偏差）；
- 若各配置偏差方向一致但幅度不同 → 优先怀疑保留系数/余隙容积而非效率。
