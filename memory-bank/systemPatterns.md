# 系统模式 (System Patterns)

## 分层架构（一个循环的模拟流水线）

```
SimConfig (params.py, JSON解析+中文校验)
   │
   ├─ motor.py     resolve_loaded_rpm(cfg, dev) → (负载RPM, MotorInfo?, BatteryInfo?)
   │     准静态法：N(T)=N0×(1−T/T堵转)；弹簧力经扇齿分度圆半径/齿比反射；
   │     平均扭矩→负载转速、峰值扭矩（拾取瞬间）→堵转判定；
   │     电池：容量×C=限流，峰值需求超限→电压按保持率跌落并缩放输出；
   │     未选型号 = 固定转速模式（标称×负载系数，默认 0.8）
   │
   ├─ timing.py    build_timeline(cfg, dev) → Timeline
   │     变转速分段角度-时间换算：拉动弧（拾取→释放）用负载转速、
   │     空转弧用近空载转速（曲线空载×负载系数；固定模式匀速）；
   │     前切→拾取角后移、后切→释放角前移、行程=剩余齿比例×满行程；
   │     凸轮槽事件固定于扇齿不随切齿移动 ← 核心机理；
   │     延时器角度级推迟（+占孔角）、切拉桥旗回位提前（含下限保护）；
   │     Timeline 含 retract_start_ms（事件表「推嘴开始缩回」时刻基准）
   │
   ├─ dynamics.py  compute(cfg, dev, tl) → Dynamics
   │     弹簧储能 E=0.5k((x0+s)²−x0²)；v_release 仅理想参考值；
   │     压气指数=行程比×气缸系数
   │
   ├─ ballistics.py compute(cfg, dev, tl, dyn) → Ballistics
   │     气垫-弹丸联动积分（步长 2μs）：开孔段自由加速→密封后绝热压缩
   │     +气垫缓冲活塞→弹丸同步加速→撞击后膨胀加速→降至大气压停止
   │     （有效推力行程）；管径-弹径间隙泄气 + 气动效率折减末动能；
   │     回位稳定 = settle_time_ms 简谐回位模型（v_r=回弹系数×撞击速度，
   │     t=2·atan(v_r/(ω·x0))/ω——刚度/预压影响复位速度）；
   │     输出初速/撞击时刻与速度/回位裕量/p_rise_ms（气密判定基准）
   │
   ├─ feeding.py   evaluate(cfg, tl) → FeedResult（窗口 vs 最小供蛋间隔）
   │
   ├─ diagnosis.py run_checks（11 项判定：电机负载/电池放电/打齿/气密时序/
   │               供蛋窗口/供蛋速率/啮合齿数/压气匹配/初速/气量管长匹配/
   │               出膛时序）+ enumerate_cut_schemes（16 方案枚举）
   │               + build_conclusion（推荐切齿/延时器/切拉桥旗/初速）
   │
   ├─ report.py    render_full(cfg) 一站式；render(...) 复用已算结果；
   │               events_list() 报告/网页共用（时刻-角度一致性已锚定）
   │
   └─ webapp.py + web/index.html（本地网页界面）
         GET /（页面）、GET /api/default、POST /api/simulate（复用引擎+校验；
         结构化结果与报告文本同源，render 复用已算结果，单次 ~37ms）
         前端单文件原生 JS：输入→150ms 防抖→POST→全量渲染；ConfigError→400
```

## 关键设计决策
1. **角度基准**：齿轮角 0° = 无切拾取角；凸轮事件固定其上，切齿移动活塞事件
   —— 由此自然导出「后切多→释放早于推嘴回位→气密不严」等现象。
2. **器件参数表（components.py）**：所有默认值集中一处，JSON 可逐项覆盖，
   便于用户实测校准；估算参数带【估算】标注。
3. **判定分级**：通过/警告/危险 三级，阈值集中在 Thresholds，可覆盖。
4. **枚举建议**：对同电机/齿比/气缸/弹簧枚举前切 0~3×后切 0~3，按「最差裕量
   归一化得分」排序；全部不达标时明确说明并指向调参方向。
5. **CLI 与网页共用同一引擎与配置格式**：网页导出 JSON 可直接给 run.py 用。
6. **哨兵约定**：无有效压气 → `Ballistics.p_rise_ms=None`（气密判定放行，
   裕量取 999）；未出膛 → `exit_ms=inf`（出膛判定显示"无有效出膛"）。

## 已知简化（精确化方向）
- 弹丸受力面积用管径面积（7.3 管/7.2 弹时约偏大 3%）、无 hop-up 启动摩擦——
  由气动效率校准旋钮吸收
- 电池续航按匀速周期+全周期拉簧平均电流估算（偏保守）
- 回弹系数（0.5）为估算值——回位稳定已按弹簧-活塞简谐模型建模
  （settle_time_ms），回弹系数待校准；整枪对比时硬簧撞得更重，
  「刚度→复位快」在同撞击条件下成立
- 超过有效推力行程的管段按"无净推力"处理（忽略背压减速）
- 水弹出管后无阻力段模型；拉桥簧柔性未建模（回位按凸轮硬性驱动，偏乐观）
