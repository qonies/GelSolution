# 项目简报 (Project Brief)

## 项目名称
GelSolution — 水弹玩具发射器波箱内部运作数据模拟

## 核心目标
纯数据模拟（无图形/动画）水弹波箱一个射击循环内各部件的运作时序，在给定
配置参数下判定：
- 是否会打齿（活塞未归位扇齿即再啮合）
- 推嘴（气密嘴）归位是否及时（气密不严）
- 供蛋时间窗口是否足够
- 压气是否不足（切齿/气缸匹配）

并给出结论建议：推荐的切齿（切蛋糕齿）方案、是否需要延时器、是否需要切拉桥旗。

## 可调输入参数
- 电机转速 RPM（标签标称值；后期用户提供电机曲线再接负载降速）
- 齿轮比：13:1 / 16:1 / 18:1
- 切齿：前切 n 齿 / 后切 m 齿 / 前后同切（前切=推迟活塞拾取，后切=提前释放）
- 气缸类型：50% / 60% / 70% / 80% / 100%
- 弹簧硬度：M75 ~ M110
- 内管长度mm（20~800）、内管管径（7.3/7.5）、水弹直径（7.2/7.3）
- 供蛋方式（按最高供弹速率，✅v0.6.5 更正）：普通波轮 30 / 高级波轮 60 /
  压力弹匣 80 发/秒

## 关键输出指标
- 水弹初速估算（m/s）+ 动能（J），超过 80 m/s（阈值可调）→ 警告
- 有效推力行程（管压降至大气压的位置），不足内管一半 → 内管过长警告

## 已确定的技术路线与约束
- Python 脚本 + JSON 参数文件（中文键）+ 命令行中文报告 + 本地网页界面；仅用标准库
- 波箱规格：通用二号波（实测基准），器件参数全部可覆盖校准
- 电机：固定转速模式（标称×负载系数）或 CHAOLI 性能曲线模式（含电池模型）
- 用户确认的术语：前切=推迟拾取、后切=提前释放；输出全中文
