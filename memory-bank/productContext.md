# 产品背景 (Product Context)

## 为什么做
水弹玩家改装波箱（切齿、换气缸、换弹簧、改供蛋）时，靠试错判断是否打齿、
气密不严、供蛋不上。本项目用数据模拟提前给出时序与风险判定，降低试错成本。

## 如何工作
- 用户写一份 JSON 配置（或改示例），运行 `python run.py -c xxx.json`
- 得到中文报告：模拟配置 → 基本时序（周期/射速/行程/储能）→ 循环事件表
  （各事件的时刻与扇齿角度）→ 11 项判定（通过/警告/危险）→ 结论建议
  （推荐切齿方案、是否需要延时器、是否需要切拉桥旗）→ 前切/后切 0~3 齿
  共 16 种方案的枚举对比表

## 用户体验目标
- 全中文输入输出，错误信息可直接读懂
- 默认参数即二号波通用值，玩家无需先研究齿数角度
- 判定分级：通过 / 警告 / 危险，直接可读
